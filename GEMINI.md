# Продолжение YAiPlay Radio

Читайте сначала `HANDOFF.md`, затем `docs/PROJECT.md`. Работайте только в `eai-apps/YAiPlay-Radio`. Не отправляйте реальные сообщения без отдельного согласия владельца; Telegram workflow безопасно запускается с `DRY_RUN=true`. Не просите секреты. Перед push — `git pull --rebase`; проверка сборки — `npm ci && npm run build`.
