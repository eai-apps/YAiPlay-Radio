# YAiPlay Radio

Отдельный проект радио YAiPlayer: сайт/PWA и Android-приложение. Основной адрес сайта — https://yaiplay-radio.pages.dev/; служебная копия GitHub Pages — https://eai-apps.github.io/YAiPlay-Radio/.

## Локальная сборка

```sh
npm ci
npm run build
```

Подробности разработки, публикации и незавершённых внешних шагов находятся в `HANDOFF.md`. Значения секретов в репозиторий не записывать.
