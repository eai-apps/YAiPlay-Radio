# YAi Radio — инструкции для помощников

- Рабочий репозиторий: `eai-apps/YAiPlay-Radio`; другой проект YAiPlayer и исходный проект не изменять.
- Ответы владельцу — по-русски, с полными путями и шагами по кнопкам, когда нужно его участие.
- Перед работой прочитать `HANDOFF.md` и `docs/PROJECT.md`; после заметной работы дописать запись в журнал HANDOFF.
- Секреты и токены не просить присылать и не сохранять в коде.
- Проверка сайта: `npm ci` и `npm run build`.
- Перед push в `main` выполнить `git pull --rebase`; Actions могут обновлять каталог.
- Реальные посты Telegram отправлять только после явного согласия владельца. Workflow только ручной, `DRY_RUN=true` по умолчанию.
- APK не подписывать, пока владелец не добавил нужные secrets; Android-публикации магазинов не запускать без отдельного решения.
- VK интеграции нет.
